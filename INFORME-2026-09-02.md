## 5) Aprendizajes clave de hoy (para aprendiz)

- **pnpm vs npm:** pnpm usa store global y `node_modules/.pnpm` aislado, evita que un paquete malicioso robe dependencias.
- **Polling:** tu laptop pregunta a Telegram cada 1s `¿algo nuevo?`; no necesitas servidor público. En Northflank seguirá con polling 24/7.
- **ctx (contexto):** carta con `from.id`, `message.text`, `reply()`. `String(ctx.from?.id || '')` convierte número a texto y evita crash con `?.`.
- **Middleware `bot.use`:** guardia que se ejecuta en **cada mensaje** (no una vez) — es local `!==` , no consume API.
- **Deprecated `bot.on("text")`:** Telegraf v5 lo quitará → usar `bot.on(message("text"))` con `import { message } from "telegraf/filters"`.
- **ESM `type: module`:** obliga a `import` en vez de `require`.
- **DeepSeek:** mismo SDK `openai`, solo cambia `baseURL`. `429 insufficient_quota` = sin saldo, no key inválida. Cache hit `$0.007` hace Guardaditos muy barato.
- **Cron `"0 7 * * *"`:** minuto 0 hora 7 todos los días, con `America/Lima` para que sea 07:00 Lima, no UTC.
